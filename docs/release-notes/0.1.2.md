# Meetless 0.1.2

## 新功能

- 项目 Agent 接入 DeepSeek：服务器开启后，自由提问由 DeepSeek 按你能看到的项目记录回答，并附引用；回答标为「DeepSeek 生成」。未开启或调用失败时仍是规则回答。
- 网页版与手机版：在浏览器里登录使用，手机上有专门的布局。
- 更新检查支持系统代理：检查和下载更新走系统的代理和 PAC 设置；检查失败时会显示「检查更新失败，点此重试」。

## New

- The project agent can use DeepSeek: when the server turns it on, free questions are answered by DeepSeek from the project record you can see, with citations, labelled "Generated by DeepSeek". Without it, or when a call fails, you get the rule answer as before.
- Web and phone: sign in from a browser, with a layout made for phones.
- Update checks use the system proxy: checking and downloading updates follow the system proxy and PAC settings, and a failed check shows "Update check failed. Click to retry".
