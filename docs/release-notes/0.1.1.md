# Meetless 0.1.1

## 安全更新

- 只打开 http 和 https 链接，服务器也拒绝其他协议的链接。
- macOS 升级前先校验签名、版本和压缩包内容，不合格的更新不会安装。
- 服务器在隔离线程里读取 DOCX 和 PDF，并限制内存、时间和大小，恶意文件不会再拖垮服务器。
- 上传先验证身份再接收数据；下载的文件不会被当作网页打开。
- 本地会话文件只有本人可读；查看代码差异时不再运行仓库里配置的外部命令。
- 发布流程收紧权限，签名证书只在签名那一步可见。
- 应用内附带许可证、第三方声明和字体许可。

建议所有用户升级。

## Security update

- Only http and https links open, and the server refuses links with any other scheme.
- On macOS, an update is installed only after its signature, version and archive contents check out.
- The server reads DOCX and PDF files in an isolated thread with memory, time and size limits, so a hostile file can no longer take it down.
- Uploads are authenticated before any data is accepted, and downloaded files are never opened as web pages.
- The local session file is readable only by you, and code diffs no longer run external commands a repository configures.
- The release workflow runs with tighter permissions, and the signing certificate is visible only to the signing step.
- The app now ships its licence, third-party notices and font licences.

Updating is recommended for everyone.
